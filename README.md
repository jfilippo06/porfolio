## 🎨 Sobre este Portafolio

* **Diseño:** Inspirado en la estética oscura de **Apple** (MacBook Pro), con fondo negro puro (`#000000`), tarjetas Bento en negro espacial (`#161617`), bordes con sutiles reflejos de luz y tipografía con degradados metálicos.
* **Arquitectura de datos desacoplada:** Todo el contenido se alimenta de un único archivo estructurado (`data/projects.ts`), permitiendo actualizar proyectos o agregar nuevos sin modificar la interfaz.
* **Rendimiento:** 100% estático y optimizado con Next.js App Router y Turbopack.

## 💻 Ejecución Local

1. Clona el repositorio:
```bash
git clone https://github.com/tu-usuario/porfolio.git
cd porfolio
```

2. Instala las dependencias:
```bash
npm install
```

3. Inicia el servidor de desarrollo:
```bash
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador.
